# TechBridge source export

Includes application source, public assets, tests, database migration files, functions, and dependency manifests.

Excluded: credentials and environment files, repository history, installed dependencies, generated build output, and private workspace metadata.

This is a code export, not a backup of live database records, uploaded storage files, or external-service account configuration.

Install dependencies using the package manifest and configure your own environment and connected services before running elsewhere.
